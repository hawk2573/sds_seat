### Data Flow for the Extension

- **Source of truth for seating:** the `Places` table.
- The extension loads all Places records (80 max, lightweight field set).
- For each Place with a non-empty `Guest` link, the extension looks up the guest in the Guests table to render the avatar / name / VIP badge.
- On drag & drop, the extension updates the `Guest` field of the affected Place records — never the Table Number / Seat Number fields on the Guests table (which are now legacy).
